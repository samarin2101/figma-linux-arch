# Figma Linux Optimizer Script

Figma Linux — популярный инструмент для дизайнеров на Linux. Однако на системах Arch и производных его запуск может требовать ручной настройки ярлыков, выбора правильных параметров для Wayland или X11 и поиска бинарников после обновлений.  

**Figma Linux Optimizer Script** решает все эти задачи автоматически: он устанавливает приложение, подстраивает запуск под вашу среду, создаёт корректный ярлык и оптимизирует работу Figma, чтобы пользователь мог сразу начать работать без лишней мороки.

---

## 🖥 Поддерживаемые системы и окружения

Скрипт предназначен для систем на основе **Arch Linux**, включая:

- Arch Linux  
- EndeavourOS  
- Garuda Linux  
- CachyOS  
- Manjaro (использование AUR неофициально)  

Поддерживаемые графические окружения:

- KDE Plasma  
- GNOME  
- Hyprland  
- Sway  
- i3 / Xorg-based DE  
- Любые среды на **Wayland** или **X11**

> Скрипт автоматически определяет, какая среда используется, и применяет оптимальные настройки.

---

## 🚀 Что делает скрипт

1. **Автоматическая установка Figma Linux через `yay`**  
2. **Создание локальной копии `.desktop` файла**  
3. **Определение среды (Wayland или X11)**  
4. **Применение оптимальных флагов запуска**  
5. **Исправление строки `Exec=`**  
6. **Поиск бинарника Figma Linux**  
7. **Перегенерация кэша KDE**  

---

## 🎯 Зачем это нужно

- Figma Linux по умолчанию не всегда корректно определяет среду.  
- Wayland и X11 требуют разных флагов для корректной работы.  
- Ручное изменение ярлыков в системных папках небезопасно.  
- Скрипт делает процесс установки и настройки полностью автоматическим.

С ним пользователю не нужно тратить время на поиск бинарников, редактирование `.desktop` файлов и подбор флагов — всё работает сразу и стабильно.
