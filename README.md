# Figma Linux Optimizer Script

Figma Linux — популярный инструмент для дизайнеров, работающих на Linux. Однако на системах Arch и производных его запуск может требовать ручной настройки ярлыков, выбора правильных параметров для Wayland или X11 и поиска бинарников после обновлений.  

**Figma Linux Optimizer Script** решает все эти задачи автоматически: он устанавливает приложение, подстраивает запуск под вашу среду, создает корректный ярлык и оптимизирует работу Figma, чтобы пользователь мог сразу начать работать без лишней мороки.

---

## 🖥 Поддерживаемые системы и окружения

Скрипт предназначен для систем на основе **Arch Linux**, включая:

- Arch Linux  
- EndeavourOS  
- Garuda Linux  
- CachyOS  
- Manjaro (использование AUR неофициально)  

Поддерживаемые графические окружения:

- KDE Plasma  
- GNOME  
- Hyprland  
- Sway  
- i3 / Xorg-based DE  
- Любые среды на **Wayland** или **X11**

> Скрипт автоматически определяет, какая среда используется, и применяет оптимальные настройки.

---

## 🚀 Что делает скрипт

1. **Автоматическая установка Figma Linux через `yay`**  
   Нет необходимости вручную искать пакет или подтверждать каждый шаг.  
2. **Создание локальной копии `.desktop` файла**  
   Позволяет редактировать ярлык без вмешательства в системные файлы.  
3. **Определение среды (Wayland или X11)**  
   Скрипт автоматически подбирает параметры запуска для вашей графической сессии.  
4. **Применение оптимальных флагов запуска**  
   Для Wayland включаются серверные декорации и нативная поддержка IME, для X11 — XWayland-параметры и оптимизация видеопамяти.  
5. **Исправление строки `Exec=`**  
   Ярлык всегда запускает приложение с нужными параметрами.  
6. **Поиск бинарника Figma Linux**  
   Скрипт находит установленный бинарник даже при нестандартной установке.  
7. **Перегенерация кэша KDE**  
   Гарантирует, что изменения ярлыка вступят в силу сразу.  

---

## 🎯 Зачем это нужно

- Figma Linux по умолчанию не всегда корректно определяет среду.  
- Wayland и X11 требуют разных флагов для корректной работы.  
- Ручное изменение ярлыков в системных папках небезопасно.  
- Скрипт делает процесс установки и настройки полностью автоматическим.  

С ним пользователю не нужно тратить время на поиск бинарников, редактирование `.desktop` файлов и подбор флагов — всё работает сразу и стабильно.
